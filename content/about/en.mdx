Hi, I am VNDR.

This is my personal website integration project. It started as a place to keep blog posts, dev logs, and scattered thoughts. Later I decided to make it a single extensible site where new modules can be added whenever needed.

This demo is built with Next.js, MDX, and Tailwind. Content is file-driven, so adding a new module mostly means adding a route and a content folder.

If you want to talk about websites, design, or development, feel free to reach out.
